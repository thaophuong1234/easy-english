## Bật GitHub Pages (1 lần)

1. Mở https://github.com/thaophuong1234/easy-english/settings/pages
2. Source: **Deploy from a branch**
3. Branch: `main` → folder `/ (root)` → **Save**
4. Đợi 1–3 phút, mở link web ở trên
